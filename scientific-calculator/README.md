# Scientific Calculator (Multi-language)

A simple, maintainable scientific calculator implemented in multiple programming languages.
Features

    Basic arithmetic: +, -, *, /

    Power: ^

    Square root: √

    Trigonometry: sin, cos, tan (radians)

    Logarithms: log (base 10), ln (natural)

## Languages

    Python

    JavaScript

    TypeScript

    Go

    Rust

    Java

    C#

## Usage

Each language folder contains a single-file implementation. Run the file directly or import the function.

## Example

```python
python3 scientific-calculator/calculator.py add 1 3
python3 scientific-calculator/calculator.py sqrt 16
python3 scientific-calculator/calculator.py sin 1.5708
```

```javascript
node scientific-calculator/javascript/calculator.js add 2 3
node scientific-calculator/javascript/calculator.js sqrt 16
node scientific-calculator/javascript/calculator.js sin 1.5708
```

```typescript
npx ts-node scientific-calculator/typescript/calculator.ts add 2 3
npx ts-node scientific-calculator/typescript/calculator.ts sqrt 16
npx ts-node scientific-calculator/typescript/calculator.ts sin 1.5708
```

```go
go run scientific-calculator/go/calculator.go add 2 3
go run scientific-calculator/go/calculator.go sqrt 16
go run scientific-calculator/go/calculator.go sin 1.5708
```
